1. Basis Set Exchange (bundled data)
-----------------------------------------------------------------------

The Gaussian basis set files in data/basis_set/ and in
cuest_scf_examples/data/gbs/ (except minao-1.gbs, see below) were
downloaded from the Basis Set Exchange
(https://www.basissetexchange.org), versions 0.9 to 0.12. The header
of each file records the Basis Set Exchange version it was downloaded
with and the origin of its data (Turbomole 7.3 for the def2 basis
sets and the cc-pVnZ-JKFIT auxiliary basis sets, ccRepo/Grant Hill
for the cc-pVnZ and aug-cc-pVnZ basis sets, Gaussian09 for STO-3G).

2. Crystallography Open Database (bundled data)
-----------------------------------------------------------------------

The urea cluster geometry
cuest_scf_examples/examples/rhf-large-1/urea_376.xyz (47 molecules,
376 atoms) was carved from the urea crystal structure in entry
1008775 of the Crystallography Open Database (COD,
https://www.crystallography.net/cod/1008775.html).

All data in the COD and the database itself are dedicated to the
public domain and licensed under the CC0 License
(https://creativecommons.org/publicdomain/zero/1.0/). The COD asks
users of the data to acknowledge the original authors of the
structural data:

  H. Guth, G. Heger, S. Klein, W. Treutmann, C. Scheringer,
  Z. Kristallogr. 153, 237 (1980).

The Crystallography Open Database is described in:

  S. Gražulis et al., J. Appl. Cryst. 42, 726 (2009).
  https://doi.org/10.1107/S0021889809016690
